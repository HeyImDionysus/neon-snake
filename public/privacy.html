NEON SNAKE

You can play every solo mode without an account. Discord sign-in is optional and exists to give you a public profile and a server-verified multiplayer record.

What we collect

If you sign in with Discord, Neon Snake stores your Discord user ID, username, display name, avatar reference, and the profile choices you submit: callsign, bio, accent color, favorite mode, and snake style.

For live rooms, we temporarily store your room presence, connection state, and match outcome. Aggregate wins, losses, and draws remain on your public profile.

For HTTP live-room requests, Neon Snake hashes the forwarded network address into a truncated anti-abuse identifier. It is used only for per-request rate limiting and automatically expires from Upstash after one second.

What stays local

Solo scores, preferences, and run reports are kept in your browser. Neon Snake does not upload them to create a hidden behavioral profile.

The Windows and Android wallpaper builds run on your device and do not require a Neon Snake account.

Discord authentication

Neon Snake requests Discord’s identify permission only. Discord access and refresh tokens are not retained after the server exchanges the one-time authorization code.

A secure, HTTP-only session cookie keeps you signed in. Activity sessions use a partitioned cookie because Discord loads the game inside an embedded frame.

How data is used

  • Display the public profile you choose to create.
  • Connect two players to the same authoritative live room.
  • Prevent duplicate result recording and maintain rankings.
  • Protect the service, diagnose failures, and enforce fair play.

Service providers

Discord provides identity and the embedded Activity surface. Vercel hosts the game and its server functions. Upstash stores sessions, profiles, room state, and records. Those providers may process basic request metadata under their own policies.

Neon Snake does not sell player data and does not use third-party advertising trackers.

Retention and control

Room presence expires automatically. Session records expire or are replaced as sessions end. Public profile and aggregate match records remain until deletion is requested.

You can sign out at any time. To request profile deletion or correction, open a privacy request in the project issue tracker without posting sensitive information.

Security and changes

We use server-side token exchange, constrained cookies, origin checks, security headers, and authoritative match validation. No internet service can promise absolute security.

Material policy changes will be posted on this page with a new effective date.
