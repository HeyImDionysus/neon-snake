# Neon Snake for Lively v1.1.2

This Windows build keeps the live wallpaper readable during long sessions. The snake visibly reaches and eats each apple, carries its lifetime score forward, and starts a fresh visual route after 42 segments instead of eventually covering the board.

Download `Neon-Snake-Lively-v1.1.2.zip`, open Lively Wallpaper, choose **Add Wallpaper**, and select the ZIP. The package is fully offline and includes configurable pace, frame rate, glow, palette, boundaries, automatic pause support, and the same autonomous engine as the website preview.
