## Android

Download `Neon-Snake-Android-v1.1.0.apk`, allow installation from your browser or file manager when Android asks, install it, open **Neon Snake Wallpaper**, and choose **Set wallpaper**. Android requires every installable APK to carry a signature, so this direct-distribution build uses the build system's debug signature; no private signing secret or store account is required. It requests no network permission and pauses when hidden.
