# Neon Snake for Lively v1.1.1

This Windows hotfix replaces the invalid v1.1.0 Lively archive. Palette and boundary dropdowns now use the integer indexes required by the official Lively Properties API, and the wallpaper maps those indexes to the correct game settings.

Download `Neon-Snake-Lively-v1.1.1.zip`, open Lively Wallpaper, choose **Add Wallpaper**, and select the ZIP. The package includes the real game planner, visible apple pickups, growth and scoring, a truthful preview thumbnail, playback pause support, and configurable pace, frame rate, glow, palette, and boundaries.
