# Neon Snake Wallpapers v1.0.0

These are permanent, versioned autonomous-wallpaper builds from verified source commit `5605378370c77a67671be57f84470bad78b546be`. GitHub Actions run 30266418551 compiled the Android package and independently rebuilt and verified the Windows package.

## Windows

Download `Neon-Snake-Lively-v1.0.0.zip`, open Lively Wallpaper, choose **Add Wallpaper**, and select the ZIP. The package runs the autonomous Neon Snake wallpaper locally.

SHA-256: `eccbf9efaa214d6ad2b06ade98b429a2810510e58aa1fddc3b90b470607590ca`

## Android

Download `Neon-Snake-Android-v1.0.0.apk`, allow installation from your browser or file manager when Android asks, install it, open **Neon Snake Wallpaper**, and choose **Set wallpaper**. This APK is installable and debug-signed for direct private distribution; it requests no network permission and includes battery-aware frame throttling.

SHA-256: `88a6f649aaa9425fd797a9e84dd5f18e0730da6b9534299b5bad334d3d3d6f59`
